# PVE 系統初始化與優化

記錄 PVE 9（Debian 13 Trixie）在台灣環境下的基本優化流程：軟體源修正、時區校時、移除訂閱到期彈窗、必要套件安裝、Datacenter Tag 樣式。

對應腳本：[`pve_config_notes.sh`](pve_config_notes.sh)

## 背景

PVE 預設安裝完成後會指向企業付費源（`enterprise.proxmox.com`），沒有訂閱金鑰時 `apt update` 會出現 401 Unauthorized。同時 Web 介面每次登入會跳出訂閱到期提示，時區預設並非台灣時區。

PVE 9／Debian 13 已將 APT 來源改為 deb822 `.sources` 格式，舊版教學文章中以 `sed` 註釋 `.list` 檔的作法在新版環境下不再適用；同時 Debian 13 預設不含 `systemd-timesyncd`，需改用 `chrony`。

## 步驟

1. 軟體源修正：清除 `pve-enterprise.list`／`.sources`／`ceph.list`，改寫為台灣 Debian 鏡像（`ftp.tw.debian.org`）與 PVE 官方 `pve-no-subscription` 源。
2. 時區與時間同步：設定 `Asia/Taipei`，改用 `chrony`，預設使用台灣公開時間伺服器（`tick.stdtime.gov.tw`、`tock.stdtime.gov.tw`、`tw.pool.ntp.org`）；若機房有內部 NTP 伺服器，可透過 `INTERNAL_NTP` 環境変數指定。
3. 移除訂閱到期彈窗：透過 APT `DPkg::Post-Invoke` Hook，在 `proxmox-widget-toolkit` 更新後自動重新修補 `proxmoxlib.js`，永久生效，不會因套件更新而失效。
4. 套件安裝與系統更新：`lm-sensors`、`smartmontools`、`linux-cpupower`、`nvme-cli`、`hdparm`、`chrony`。
5. Datacenter Tag 樣式：設定 `tag-style: shape=full,ordering=alphabetical`，讓虛擬機標籤顯示為完整圓角膠囊、按字母排序。

## 使用方式

本篇腳本負責系統本身的設定，會安裝 disk_monitor.sh（見硬體監控客製化文章）所需要的 smartmontools、nvme-cli、hdparm 等工具。建議在新機上依下列順序執行：

curl -fsSL https://raw.githubusercontent.com/sungshu/pve_config_notes/main/src/pve/pve_config_notes.sh -o pve_config_notes.sh
chmod +x pve_config_notes.sh
./pve_config_notes.sh

若機房有內部 NTP 伺服器（IP 僅為範例，請換成實际位址）：

INTERNAL_NTP=192.168.0.100 ./pve_config_notes.sh

等第一步完成、套件安裝完畢後，再下載並執行硬體監控客製化：

curl -fsSL https://raw.githubusercontent.com/sungshu/pve_config_notes/main/src/pve/disk_monitor.sh -o disk_monitor.sh
chmod +x disk_monitor.sh
./disk_monitor.sh

兩支腳本互相獨立，disk_monitor.sh 不會被 pve_config_notes.sh 自動呼叫，需要手動接續執行第二步。

## 注意事項

- apt update 對單一來源失敗時不會中止整支腳本（加了警告訊息），避免台灣鏡像或 PVE 源暫時性問題卡死後續步驟。
- APT Hook 的 sed 表達式需精確比對狀態字串，若 PVE 版本更新後 proxmoxlib.js 內部邏輯改変，此 Hook 可能失效，需重新確認。
- 系統層設定（軟體源、時區、Chrony、Hook、Tag 樣式）為直接覆寫，不提供自動還原，如需還原請手動處理對應設定檔。
