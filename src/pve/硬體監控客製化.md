# PVE 硬體監控客製化

> **正式版：disk_monitor.sh v1.0.52**  
> 更新日期：2026-09-01

本版本以目前 PVE 實機已確認正常顯示的版本為正式基準，將 CPU、雙插槽溫度、網卡溫度、NVMe、SATA/SAS、MegaRAID Physical Disk 整合至 PVE Node Summary。

## v1.0.52 保留的穩定機制

1. **CPU 狀態與雙插槽溫度**：精準 Hook 在 `render_cpu_model` 後方，自動分行顯示 `CPU1`～`CPUn` 與 `網卡1`～`網卡n`。
2. **磁碟與 RAID 列表**：精準 Hook 在 `pveversion` 後方，直通硬碟與 MegaRAID 實體硬碟自動分流呈現。
3. **Auto-Height 自適應**：Node Summary 使用 `height: "auto"`，支援 15 顆以上磁碟且不遮擋右側圖表。
4. **All-in-One**：自動建立 `/etc/cron.d/disk_monitor`，提供 `install`、`collect`、`restore`、`remod` 流程。
5. **API 非同步採集**：`smartctl`、`sensors`、`turbostat` 不在 PVE API request 中執行；`Nodes.pm` 僅讀取 `/run/disk_monitor_runtime/`。
6. **官方檔案備份保護**：依 PVE 版本建立 `/var/lib/disk_monitor/<PVE版本>/`，若既有 backup 含舊注入則拒絕覆蓋。

## 硬體資料

### CPU

- CPU 即時 MHz
- 平均／最低／最高頻率
- CPU scaling governor
- CPU package `PkgWatt`（若主機支援 turbostat）
- `sensors` CPU 溫度
- 多 CPU / 多插槽分行顯示

### 網卡

支援從 `sensors` 輸出的網卡感測器辨識並標示為 `網卡1`、`網卡2`……，避免與 CPU 溫度混在一起。

### NVMe

顯示：

- 型號
- 溫度
- 健康度
- 通電時數
- 開關機次數
- 讀取 TB / 寫入 TB
- SMART 狀態

### SATA / SAS

依 `TRAN` 與 `ROTA` 分類：

| 條件 | 類型 |
|---|---|
| `TRAN=sata` + `ROTA=0` | SATA 固態硬碟 |
| `TRAN=sata` + `ROTA=1` | SATA 傳統硬碟 |
| `TRAN=sas` + `ROTA=0` | SAS 固態硬碟 |
| `TRAN=sas` + `ROTA=1` | SAS 傳統硬碟 |

資料由背景 `collect` 採集，UI 僅解析 JSON，不於 API request 執行硬體 command。

### MegaRAID

使用 `smartctl -d megaraid,N /dev/bus/0` 掃描 Physical Disk，並透過 Serial / WWN 建立 `/dev/sdX` 與 RAID Physical Disk 的對應，避免 RAID 磁碟被誤列為一般 SATA/SAS 硬碟。

## 精準 Hook

### CPU 區塊

注入點位於 `render_cpu_model` 結尾之後，確保 CPU 型號後緊接 CPU 運作狀態與 CPU 溫度。

### 磁碟區塊

注入點位於 `textField: 'pveversion'` 區塊結尾之後，所有磁碟資訊以全寬區塊向下展開。

### Auto-Height

Node Summary 的固定高度改為：

```text
height: "auto", minHeight: 300
```

因此硬碟數量增加時由 ExtJS 自動增加容器高度。

## 使用方式

```bash
chmod +x /root/disk_monitor.sh
/root/disk_monitor.sh
```

### 背景採集

```bash
/root/disk_monitor.sh collect
```

Cron：

```text
/etc/cron.d/disk_monitor
```

每分鐘執行一次 `collect`。

### 還原官方 PVE UI

```bash
/root/disk_monitor.sh restore
```

### 重新套用

```bash
/root/disk_monitor.sh remod
```

## 驗證

```bash
jq empty /run/disk_monitor.json
pvesh get /nodes/localhost/status --output-format json | jq '.cpuFreq,.thermalstate'
```

套用或還原後，瀏覽器執行：

**Ctrl + F5**

## 注意事項

- PVE 更新後 `Nodes.pm` 或 `pvemanagerlib.js` 結構可能變更；執行 `remod` 前應確認目前 PVE 版本。
- 本 v1.0.52 以目前實機已確認正常顯示的 Hook 與資料採集架構為正式基準，不應以舊版 GitHub 腳本覆蓋。
- `PkgWatt` 為 CPU package 功耗參考值，不代表整機功耗。
