# PVE 硬體監控客製化

記錄如何在 PVE 9 的 Node Summary 摘要頁面，加入繁體中文的 CPU 溫度／頻率／功耗，
以及 NVMe、SATA、SAS、PERC/MegaRAID 硬碟的型號、溫度、通電時數與 SMART 狀態顯示。

對應腳本：[`disk_monitor.sh`](disk_monitor.sh)

## 開發背景

最初參考對岸開源專案 `a904055262/PVE-manager-status` 的 `showtempcpufreq.sh`，
但實際使用後發現不符合需求：

- 沒有 SAS 硬碟與 PERC/MegaRAID 虛擬磁碟的分類邏輯，容易誤判。
- 介面文字為簡體中文。
- 未見明確證據顯示已針對 PVE 9 的 `Nodes.pm`／`pvemanagerlib.js` 新結構做相容性
  驗證。

因此改為完全自行開發，依照本機實際偵測到的硬碟數量動態產生對應區塊，並補上 SAS、
RAID 虛擬磁碟判斷。

## 磁碟分類規則

判斷順序固定如下，全部在腳本執行時即時偵測完成（不使用背景快取）：

| 順序 | 判斷條件 | 分類 | 顯示標籤 |
|---|---|---|---|
| 1 | `smartctl --scan-open` 找到 `megaraid,N` | RAID 硬碟（實體碰） | `RAID 硬碟 N (控制器型號)` |
| 2 | 型號含 PERC/MegaRAID/RAID | 跳過一般判斷 | 由規則 1 涵蓋，避免誤判為傳統硬碟 |
| 3 | `TRAN=sata`，`rotational=0` | SATA SSD | `SATA 固態硬碟N` |
| 4 | `TRAN=sata`，`rotational=1` | SATA HDD | `SATA 傳統硬碟N`（可做 standby 判斷） |
| 5 | `TRAN=sas`，`rotational=0` | SAS SSD | `SAS 固態硬碟N` |
| 6 | `TRAN=sas`，`rotational=1` | SAS HDD | `SAS 傳統硬碟N`（不做 standby 判斷） |

SMART 讀取失敗或狀態異常時，介面會直接顯示紅字 `SMART: FAIL`，不會靜默略過。

## 效果

- HBA 直通環境：NVMe（Dell BOSS-N1）、SAS 固態硬碟（KIOXIA）、SAS 傳統硬碟
  （SEAGATE）皆正確顯示型號、溫度、通電時數、SMART 正常。
- PERC H755 RAID 環境：標籤正確顯示為 `RAID 硬碟 0～4 (PERC H755)`，透過
  `smartctl -d megaraid,N` 讀出型號、溫度、SMART 狀態，不會被誤判成一般機械硬碟
  或標示為「休眠中」。

## 使用方式

```bash
chmod +x disk_monitor.sh
./disk_monitor.sh          # 套用修改
./disk_monitor.sh restore  # 還原官方原始檔案
./disk_monitor.sh remod    # 強制重新套用（先還原再套用）
```

## 注意事項

- 隨著 PVE 版本迭代，`Nodes.pm`／`pvemanagerlib.js` 的插入點字串（如
  `PVE::pvecfg::version_text()`）可能改變，執行前請先在測試節點驗證。
- PERC/MegaRAID 環境的判斷同時依賴 `smartctl --scan-open` 的裝置對應與型號關鍵字，
  不同控制器與驅動程式差異較大，請以實機輸出核對結果。
- `turbostat` 的 `PkgWatt` 僅為 CPU 封裝功耗參考值，非整機功耗，整機用電請以
  iDRAC / iLO / Redfish 等 BMC 介面為準。
