# PVE 系統初始化與優化

記錄 PVE 9（Debian 13 Trixie）在台灣環境下的基本優化流程：軟體源修正、時區校時、
移除訂閱到期彈窗、必要套件安裝、Datacenter Tag 樣式。

对應腳本：[`src/pve/pve_config_notes.sh`](../src/pve/pve_config_notes.sh)

## 背景

PVE 預設安裝完成後會指向企業付費源（`enterprise.proxmox.com`），沒有訂閱金鑰時
`apt update` 會出現 401 Unauthorized。同時 Web 介面每次登入會跳出訂閱到期提示，
時區預設亮非台灣時區。

PVE 9／Debian 13 已將 APT 來源改為 deb822 `.sources` 格式，舊版教學文章中以 `sed`
註釋 `.list` 檔的作法在新版環境下不再適用；同時 Debian 13 預設不含
`systemd-timesyncd`，需改用 `chrony`。

## 步驟

1. **軟體源修正**：清除 `pve-enterprise.list`／`.sources`／`ceph.list`，改寫為台灣
   Debian 鏡像（`ftp.tw.debian.org`）與 PVE 官方 `pve-no-subscription` 源。
2. **時區與時間同步**：設定 `Asia/Taipei`，改用 `chrony`，預設使用台灣公開時間
   伺服器（`tick.stdtime.gov.tw`、`tock.stdtime.gov.tw`、`tw.pool.ntp.org`）；若
   機房有內部 NTP 伺服器，可透過 `INTERNAL_NTP` 環境變數指定。
3. **移除訂閱到期彈窗**：透過 APT `DPkg::Post-Invoke` Hook，在
   `proxmox-widget-toolkit` 更新後自動重新修補 `proxmoxlib.js`，永久生效，不會
   因套件更新而失效。
4. **套件安裝與系統更新**：`lm-sensors`、`smartmontools`、`linux-cpupower`、
   `nvme-cli`、`hdparm`、`chrony`。
5. **Datacenter Tag 樣式**：設定 `tag-style: shape=full,ordering=alphabetical`，
   讓虛擬機標籤顯示為完整圓角膠囊、按字母排序。

## 使用方式

```bash
chmod +x pve_config_notes.sh disk_monitor.sh

# 套用全部優化（系統設定 + 硬碟監控介面，硬碟監控見另一篇文章）
./pve_config_notes.sh

# 若機房有內部 NTP 伺服器（IP 僅為範例，請換成實际位址）
INTERNAL_NTP=192.168.0.100 ./pve_config_notes.sh
```

## 注意事項

- `apt update` 对单一來源失敗時不會中止整支腳本（加了 `|| echo 警告...`），避免
  台灣鏡像或 PVE 源暫時性問題卡死後續步驟。
- APT Hook 的 `sed` 表達式需精確比對 `data.status` 與 `active` 字串，若 PVE 版本
  更新後 `proxmoxlib.js` 內部邏輯改変，此 Hook 可能失效，需重新確認。
- 系統層設定（軟體源、時區、Chrony、Hook、Tag 樣式）為直接覆寫，不提供自動還原，
  如需還原請手動處理对應設定檔。
